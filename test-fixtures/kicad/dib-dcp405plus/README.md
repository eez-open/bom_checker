# EEZ DIB DCP405plus (KiCad 10)

The KiCad project of the EEZ DIB DCP405plus power module, used as a real-world test case for KiCad import. The files are gzipped copies of the `KiCad` folder at commit `4d7d253ddcc1d7eed47cf06890cebf837577951b` of <https://github.com/eez-open/dib-dcp405plus>.

`BOM example.csv` in the repository root is the Symbol Fields Table export of the same project (Default variant), so the import can be checked against what KiCad itself produces.
